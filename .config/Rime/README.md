# 鼠须管：五笔 86

默认只匹配五笔 86；需要查字时输入 `z` + 拼音，候选旁显示对应的五笔编码。中文使用鼠须管，英文使用 macOS 自带 ABC，通过系统 Fn 切换；Shift 不切换中英文。

## 目录与 yadm

配置实际存放在 `~/.config/Rime`，鼠须管通过符号链接读取：

```text
~/Library/Rime → ../.config/Rime
```

yadm 只跟踪 `~/.config/Rime` 下的配置、原始码表和脚本。`~/Library/Rime` 链接由 `install.sh` 在本机创建，不纳入 yadm；`~/.gitignore` 排除该链接及迁移备份目录。链接使用相对路径，支持不同用户名的新电脑。

`.gitignore` 也放在 `~/.config/Rime`。`build/`、`sync/`、`*.userdb/`、`*.userdb.*`、`user.yaml`、`installation.yaml` 和日志为本机生成数据，不纳入 yadm。现有学习词库随本次目录迁移保留；新电脑不会自动恢复个人学习词库。

## 新电脑安装

要求 macOS 13 或更新版本，并能访问 GitHub。脚本使用系统自带工具，无需 Homebrew、Xcode 或管理员密码。

1. 安装 yadm，并从自己的 dotfiles 仓库恢复配置：

   ```bash
   brew install yadm
   yadm clone <你的-dotfiles-仓库地址>
   ```

   此处使用 Homebrew 安装 yadm；已经安装 yadm 时跳过第一条命令。鼠须管安装本身不依赖 Homebrew。

2. 执行：

   ```bash
   ~/.config/Rime/install.sh
   ```

3. 首次安装后注销并重新登录，在输入法菜单选择“鼠须管”。如菜单未出现，在“系统设置 → 键盘 → 文本输入 → 编辑 → ＋ → 简体中文”添加鼠须管。保留 ABC，将系统 Fn 键设置为“更改输入法”，即可继续用 Fn 切换。

`install.sh` 会完成：

- 优先复用当前用户或系统已经安装的鼠须管，不覆盖或降级已有版本。
- 未安装时下载官方 **1.1.2** 安装包，校验固定 SHA-256、安装包签名和程序签名，安装到 `~/Library/Input Methods/Squirrel.app`。
- 创建 `~/Library/Rime` 相对链接。若该路径已有其他目录、文件或链接，先停止鼠须管，将原内容保存到 `~/Library/Rime.backup.XXXXXX/Rime`，再创建链接；不会删除旧配置或词库。
- 注册并启用简体鼠须管，编译五笔配置，启动程序并通知它加载配置。

脚本可重复运行，已有正确链接时不再备份，也不会修改 Fn 设置或禁用其他系统输入法。通过本脚本安装的鼠须管不登记为 Homebrew cask；可从鼠须管菜单检查程序更新。修改脚本中的下载版本时需同时更新对应 SHA-256。

## 更新与维护

| 操作 | 方法 |
|---|---|
| 新电脑安装、创建或修复链接 | `~/.config/Rime/install.sh` |
| 更新鼠须管程序 | 输入法菜单 → “检查更新…” |
| 修改配置后使其生效 | `~/.config/Rime/deploy.sh` 或菜单“重新部署” |
| 同步自己保存的配置 | `yadm pull`，然后执行 `deploy.sh` |

`install.sh` **不会升级已有的鼠须管**：发现程序后直接复用，仅在未安装时下载脚本锁定的 1.1.2。即使程序已经更新到更高版本，再运行脚本也不会降级。更换新电脑默认安装版本，需要同时修改脚本中的版本号和 SHA-256。

鼠须管内置自动检查更新功能，也可主动在菜单中检查；是否自动检查可受本机更新偏好设置影响。发布没有固定周期，例如 1.0.3 发布于 2025-01-23，1.1.0 和 1.1.1 发布于 2026-01-11，1.1.2 发布于 2026-01-13。一般按程序提示更新，或在 macOS 升级、出现兼容性问题时检查即可，无需频繁运行安装脚本。发布记录见 https://github.com/rime/squirrel/releases 。

程序更新与五笔码表更新分开处理：应用更新会保留本目录中的个人配置；此处随 yadm 保存的五笔码表不会自动跟随应用更新。`deploy.sh` 只编译本地配置，不下载程序或新码表。应用升级后如需重新加载配置，可再运行 `deploy.sh`。

## 简洁使用说明

候选横排显示，每页 5 项，隐藏上下页提示。

| 操作 | 按键 |
|---|---|
| 五笔 / ABC 切换 | Fn |
| 上一个 / 下一个候选 | ← / → |
| 上一页 | ↑ 或 `-` |
| 下一页 | ↓ 或 `=` |
| 确认当前候选 | 空格或回车 |
| 原样输出当前输入的英文，不切换输入法 | Shift + Enter |
| 直接选择当前页候选 | 数字 `1`～`5` |
| 取消当前输入 | Esc |
| 拼音查字及五笔编码 | `z` + 拼音，例如 `zni`、`znihao` |
| 中文模式输入半角 `@` | 直接按 `Shift + 2`（ABC 键盘布局） |

普通输入不匹配拼音。忘记五笔编码时，输入 `zni` 可找到“你”，并在候选旁看到 `wq`、`wqi`、`wqiy` 等五笔编码；`znihao` 可找到“你好”，并查看它的五笔编码。左右键选字、空格或回车确认，Esc 取消查字。五笔候选确实只有一项时自动上屏，例如 `imya` → “测试”；存在多个候选时等待选字。中文默认半角模式下，`@` 直接输出半角符号，不再打开符号候选，便于聊天时提及他人。尚未确认的编码，按 Fn 切换至 ABC 时输出原始字母；已自动上屏或确认的汉字不会还原成字母。

为避免误触改变输入方式，关闭了 `Ctrl + Shift + 数字`（包括对应符号键）的内部英文、全角等模式切换，以及 `Ctrl + 反引号`、`Ctrl + Shift + 反引号`、F4 的方案菜单快捷键。Shift、Caps Lock 和英数键也不再由 Rime 用于切换模式或清空编码；系统键盘的大写锁定行为仍由 macOS 处理。英文继续使用 Fn 切换到系统 ABC，Shift + Enter 仍可临时原样输出英文。

### 聊天时输入 @

按 **Shift + 2** 输出半角 `@`。五笔方案关闭了默认的邮箱识别：否则尚未确认的编码后输入 `@`（如 `a@`、`zni@`）会进入邮箱识别状态，字符仍留在输入法预编辑中，应用尚未收到已提交的 `@`。

关闭后，有中文候选时会提交当前高亮候选和 `@`；没有候选时提交原始字母和 `@`，例如 `channel@`。不自动添加空格。真正输入邮箱地址时请按 Fn 切换 ABC，避免邮箱前缀被当作五笔编码。

这项修正只使用 `wubi86.custom.yaml`，不使用 Lua。已用原生引擎验证字符提交；2026-11-13 在 Telegram 中手动验证“空输入框按 Shift + 2”和“输入 a、不按空格，再按 Shift + 2”，两种情况均立即显示提及列表。Lark 尚未单独验证；提及位置仍需符合应用自身的规则。

## 临时输入英文

在五笔模式下输入英文字母后，按 **Shift + Enter** 可原样输出当前尚未上屏的输入，并继续保持五笔模式；即使当前有中文候选也可使用。

例如输入 `helloworld`、`docker`、`configuration` 后按 Shift + Enter，会分别输出原始单词，不会带入预编辑中自动添加的拆分空格（如 `he ll o wo rld`）。原始输入中已有的空格会保留，不会一律删除空格。普通回车仍确认当前中文候选。

普通五笔字词按一至四码匹配，已关闭拆分编码自动造句以及无匹配时回退提交前一段的行为。输入到第五个字母仍无完整匹配时，会保留原始字母，不再拼成多个汉字；没有启用“四码顶字”。例如：

- 输入 `channel` 后按 Shift + Enter，输出 `channel`。
- 输入 `channel_` 时，下划线使当前无匹配的原始英文和半角 `_` 直接上屏，输出 `channel_`，不会变成汉字。
- 输入 `channel_name` 后按 Shift + Enter，输出 `channel_name`。

一至四码内真正唯一的五笔候选仍会自动上屏，例如 `imya` → “测试”。因此，如果某段英文前缀恰好是唯一五笔编码，仍可能在第五个字母之前上屏；已经上屏的内容不能通过后续字母或 Shift + Enter 撤回。长段英文建议使用 ABC。

此功能只处理仍在输入框中、尚未上屏的内容；已经自动上屏的汉字无法通过它还原。普通空格仍用于确认中文候选，不会把空格追加到英文缓冲区；输入含空格的英文句子、网址或代码，建议按 Fn 切换 ABC。没有待确认输入时，Shift + Enter 继续交给当前应用处理。

## 符号与全半角

默认使用半角字符和中文标点，每次进入五笔方案时恢复这两个默认选项。

| 输入 | 输出 |
|---|---|
| `, . ? ! : ;` | `，。？！：；` |
| 双引号、单引号 | 交替输出 `“”`、`‘’` |
| `( )` | `（）` |
| `< >`（Shift + 逗号 / 句号） | 直接输出书名号 `《》` |
| `@ # % * /`、反斜杠、`_ = + -` | 直接输出对应半角符号 |

候选菜单打开时，`-`、`=` 继续用于上一页、下一页；没有候选时才输出符号。逗号和句号不参与翻页，即使已经翻到后面的候选页，也只负责输入中文 `，`、`。`；仍有候选时会先提交当前高亮候选，再输出标点。由于 `/` 改为直接上屏，不再通过 `/fh` 等斜杠前缀输入符号候选。中文普通标点维持中文形式，英文、网址和代码仍推荐按 Fn 切换到 ABC 输入。

## 修改与重新部署

| 文件 | 用途 |
|---|---|
| `default.custom.yaml` | 默认五笔 86、关闭内部模式切换快捷键、保留编辑和 -/= 翻页 |
| `wubi86.custom.yaml` | 五笔输入、全半角及标点、唯一候选自动上屏、回车选字、Shift + Enter 原样输出英文和方向键操作 |
| `squirrel.custom.yaml` | 候选横排显示、隐藏上下页提示、终端和编辑器默认中文 |
| `wubi86.*.yaml` | 官方五笔 86 方案和码表 |
| `pinyin_simp.*.yaml` | 仅供 `z` 键拼音查字及五笔编码反查，不作为单独可切换方案出现 |

修改配置后执行：

```bash
~/.config/Rime/deploy.sh
```

也可在鼠须管菜单选择“重新部署”。原始码表和方案保持上游内容，个人调整写在 `*.custom.yaml` 中。

保存到 yadm：

```bash
yadm add ~/.config/Rime
yadm commit -m "feat: configure Rime Wubi86"
yadm push
```
